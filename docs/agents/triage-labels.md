# Triage-Labels

| Rolle | Label im Tracker | Bedeutung |
| --- | --- | --- |
| needs-triage | needs-triage | Bewertung durch Maintainer erforderlich |
| needs-info | needs-info | Weitere Informationen erforderlich |
| ready-for-agent | ready-for-agent | Vollständig spezifiziert, für Agent bereit |
| ready-for-human | ready-for-human | Umsetzung durch Menschen erforderlich |
| wontfix | wontfix | Wird nicht umgesetzt |

Bei einer Triage-Rolle das zugeordnete Label verwenden.
